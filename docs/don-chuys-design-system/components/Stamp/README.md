Circular sticker with rotating text around a centre icon: the brand's playful seal for heroes and promos.

**Consumer provides:** `text` (end with ` · ` so it loops; about 30 characters), `icon`, `tone` (`postmark` — outline rose seal, no spin — | `marigold` | `rose` | `teal`), `size` (px), `spin` (default true; stops for reduced motion).

- One stamp per viewport, overlapping an image corner.
- Decorative only (hidden from screen readers): never the only place information lives.
