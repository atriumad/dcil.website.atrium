Call-to-action in the site's shape: 4px corners, small uppercase label. `primary` is the site's `chuy-red` "View Menu" button.

**Consumer provides:** `children` (label), `variant` (`primary` | `outline` | `rose` | `navy` | `teal` | `marigold` | `ink` | `cream`), `size` (`sm` | `md` | `lg`), optional `icon` (trailing, e.g. `arrow-right`, `arrow-up-right` for external), `iconLeft` (e.g. `pin`), `href` to render a link, native button props.

- One `primary` per viewport. Pair it with an `outline` secondary.
- Hover darkens the fill; the trailing arrow nudges right. `outline` fills on hover. Focus shows a 3px `focus` ring.
- On `marigold` grounds use `ink`; on `sage`, `agave` or photos use `cream`; on `chuy-rose` use `marigold`.
- Labels: 1–3 words, title case, verb first: View Menu, Order Online, Book a Table, Get Directions.
