Image frame in brand shapes: `arch` (Mexican doorway), `circle` (cut-out plate), `rounded`, `ticket`, `polaroid` (white border with tape, for collage panels).

**Consumer provides:** `src`, `alt` (describe the dish), `shape`, optional `ratio` (CSS aspect-ratio), `sticker` (price pill text), `ground` (token behind transparent or loading images).

- `circle` carries `shadow-plate` and is for top-down plate shots only.
- `arch` for hero and story photos; add a 3px `ink` border in heroes.
- Without `src` it shows a placeholder, never a stock photo.
