Big colour tiles for menu categories: Eudora name, script note, a plate peeking from the corner (or a large icon) and an arrow.

**Consumer provides:** `items` `[{name, note, image | icon, tone, href}]` (tones cycle rose, agave, marigold, sage).

- 4 across on desktop, 2 on tablet, 1 on phone. Hover lifts the tile and spins the plate.
