Rounded uppercase label from the posters: taglines, day tags, price stickers, dietary tags.

**Consumer provides:** `children`, `tone` (`outline` | `agave` | `white` | `marigold` | `rose` | `ink`), `size` (`md` | `sm`), optional `icon`.

- A label, not a button: never clickable.
- `outline` inherits the text colour of its ground.
- `white` + `shadow-lift` is the floating price sticker; max one per composition.
- Dietary tags use `sm`: `rose`+`chile` for Spicy, `agave` for everything else.
