Horizontal talavera-tile strip used as a divider between page chapters and on top of the footer.

**Consumer provides:** `tone` (`fiesta` — default, the multicolour site-palette tile — or single-ink `agave` | `rose` | `marigold` | `sage`), `height` (px, default 48), `edge` (`both` | `top` | `none` for the ink rules).

- Place full-bleed, never inside cards. At most two per page.
- The tile is an original geometric pattern; the ink comes from the tone, the ground is its paired tint.
