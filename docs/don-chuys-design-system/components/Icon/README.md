Original line icon set (22 icons, 24px grid, 2px round stroke) drawn for Don Chuy's: food & drink (chile, lime, avocado, taco, corn, agave, margarita, beer, flame, utensils, sparkle) and UI (pin, clock, phone, calendar, bag, mail, arrows, menu, close, plus).

**Consumer provides:** `name` (see `Icon.names`), optional `size` (default 24), `title` when the icon carries meaning on its own (otherwise it is hidden from screen readers), `strokeWidth`.

- Icons inherit `currentColor`: colour them through the parent (`ink`, `chuy-rose`, `agave`).
- Sizes: 16 in dense lists, 18–20 inside buttons, 24 default, 28+ decorative.
- Pair an icon with a word. Never use icons alone for price, hours or allergens.
- `sparkle` is the brand's separator and eyebrow mark; use it, not bullets or emoji.
