`fiesta-tile` (80px, multicolour in the site palette: teal lattice, rose/marigold flower, red centre, navy corners) is the v4 web tile for `TileBand` and `ColorSplit`; it is used as-is, not recoloured. The others are original single-ink repeat tiles, drawn in `agave` (#35544e). In code they are CSS masks coloured by any token (`Pattern`, `TileBand`). `talavera-tile` (80px, geometric four-petal tile) for bands, dish cards and poster edges; `doodles` (240px, scattered food icons) behind heroes and promos; `diamond` (24px) as quiet texture on dark bands; `scallop` (32×12) as a papel-picado edge. Always behind content at low contrast.
